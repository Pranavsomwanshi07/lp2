# Case Study on Amazon Web Services EC2

## Introduction

Amazon EC2 (Elastic Compute Cloud) is a web service provided by [Amazon Web Services (AWS)](https://aws.amazon.com?utm_source=chatgpt.com).
It allows users to rent virtual computers (servers) on the cloud to run applications, websites, databases, and software.

EC2 provides:

* Virtual servers in the cloud
* Scalable computing power
* Secure and reliable infrastructure
* Pay-as-you-use pricing

---

# What is Amazon EC2?

Amazon EC2 is a cloud computing service that provides virtual machines called **Instances**.

Instead of buying physical computers or servers, users can launch EC2 instances online and use them anytime.

### Full Form

EC2 = Elastic Compute Cloud

### Main Purpose

* Hosting websites
* Running applications
* Data storage and processing
* Machine learning
* Game servers
* Business applications

---

# Features of Amazon EC2

## 1. Elastic Scaling

Users can increase or decrease server capacity according to demand.

Example:

* During festival sales, shopping websites need more servers.
* After traffic decreases, servers can be reduced.

---

## 2. Pay-As-You-Go Pricing

Users pay only for the resources they use.

Benefits:

* No need to buy expensive hardware
* Cost saving
* Suitable for startups and students

---

## 3. Multiple Operating Systems

EC2 supports:

* Linux
* Windows
* Ubuntu
* Red Hat

---

## 4. Security

AWS provides:

* Firewalls
* Security groups
* Encryption
* Access control using IAM

---

## 5. High Availability

EC2 servers are available in multiple regions and availability zones.

This helps:

* Reduce downtime
* Improve reliability
* Ensure backup support

---

# Components of EC2

| Component      | Description                                   |
| -------------- | --------------------------------------------- |
| Instance       | Virtual server                                |
| AMI            | Amazon Machine Image used to create instances |
| EBS            | Storage volume for EC2                        |
| Security Group | Virtual firewall                              |
| Key Pair       | Login authentication                          |
| Elastic IP     | Static public IP address                      |

# Working of Amazon EC2

## Step 1: Login to AWS

Open AWS Management Console.

[AWS Console](https://console.aws.amazon.com?utm_source=chatgpt.com)

---

## Step 2: Launch Instance

Choose:

* Operating System
* Instance type
* Storage
* Security settings

---

## Step 3: Connect to Instance

Use:

* SSH for Linux
* Remote Desktop for Windows

---

## Step 4: Deploy Application

Install software or upload website/application files.

# Advantages of Amazon EC2

Simple web interface for launching servers.

## Cost Effective

No need for physical hardware.

## Scalable

Resources can be increased anytime.

## Reliable

# Disadvantages of Amazon EC2

* Monthly cost may increase for large usage
* Beginners may find configuration difficult
